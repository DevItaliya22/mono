# Generated references

Every file here is **generated from the code and never hand-edited**. A test in
the generating crate asserts that the checked-in file matches what the code
produces, so a change to the source that is not regenerated here fails that
crate's tests. To change one, change its source and regenerate. They live in
this repository, not in `docs/`, so the tree builds and tests without the docs
checkout and the references stay public next to the code that writes them.
